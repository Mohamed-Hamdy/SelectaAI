# Selecta AI
Select text in any app, press **Ctrl+Alt+Shift+Space**, and get a clean AI prompt in a small popup. Edit it, then paste it back or send it to ChatGPT, Claude or Gemini.

## Download
[Download the latest version for Windows](https://github.com/Mohamed-Hamdy/SelectaAI/releases/latest), run the installer. If SmartScreen warns, click *More info → Run anyway*.
The app updates itself.
